# Chatbot_Deepseek_R1
LangChain DeepSeek-R1 Chatbot

This project is a chatbot built using LangChain, Ollama LLM (DeepSeek-R1), and Streamlit for an interactive user interface. It allows users to ask questions and receive intelligent responses.

🚀 Features

Uses DeepSeek-R1 LLM for generating responses

Built with LangChain for prompt management and LLM integration

Streamlit for an interactive web UI

.env support for API key management

📌 Installation

Ensure you have Python installed, then install the required dependencies:

pip install langchain langchain_community langchain_core langchain_ollama streamlit python-dotenv
